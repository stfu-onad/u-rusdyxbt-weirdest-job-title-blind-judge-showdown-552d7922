## The entry

`main.py` writes a single original job title to `/output/entry.txt`:

> **Senior Director of Squirrel Diplomacy**

A dead-serious corporate title with one gloriously specific twist: a
senior director whose entire portfolio is negotiating with squirrels.
37 characters, one line — weird, funny on first read, and specific
enough to picture the person doing it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
